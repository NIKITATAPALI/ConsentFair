# ConsentFair: A Forensic Framework & Tool for Cookie Consent Compliance

**ConsentFair** is a comprehensive research-grade toolkit and browser extension designed to identify, quantify, and report deceptive design practices (Dark Patterns) in cookie consent interfaces. This project maps real-world UI/UX behaviors against the **General Data Protection Regulation (GDPR - EU)** and the **Digital Personal Data Protection (DPDP) Act 2023 (India)**.

---

## 📁 Directory Structure & File Manifest

### 1. Browser Extension (`/`)
*   **`manifest.json`**: The extension configuration. Enables iframe-scanning and forensic data permissions.
*   **`content.js`**: The detection engine. Scans DOM/iframes for banners, scrolls to evidence, and calculates visual saliency.
*   **`background.js`**: The orchestrator. Manages background audits, forensic session wiping (clearing cookies/cache), and screenshot capture.
*   **`rules.js`**: The scoring brain. Implements the 10-category Dark Pattern engine and legal mapping logic.
*   **`dashboard.html/js`**: The full-page Researcher Dashboard for bulk scanning and live analytics.
*   **`popup.html/js`**: The primary UI for single-site forensic audits.
*   **`styles.css`**: Professional dark-themed UI styling for the extension and dashboard.

### 2. Research & Documentation (`/GDRP` & Root)
*   **`revised_research_paper.tex`**: The complete 6-page IEEE conference paper (LaTeX).
*   **`references.bib`**: BibTeX file with 20+ high-impact academic citations.
*   **`ConsentFair_Complete_Project_Report.pdf`**: Full project documentation and handoff record.
*   **`ConsentFair_Audit_*.html`**: Examples of forensic reports generated by the tool.

## 🛠️ How to Execute

### A. Initial Setup (Browser Extension)
1.  Open **Google Chrome** and go to `chrome://extensions`.
2.  Enable **Developer mode** (toggle in the top-right).
3.  Click **Load unpacked** and select the root folder containing the extension files.
4.  Pin **ConsentFair** to your browser toolbar.

### B. Performing a Single-Site Forensic Audit
1.  Navigate to any website (e.g., `theguardian.com` or `linkedin.com`).
2.  Open the **ConsentFair** popup from the toolbar.
3.  Ensure the toggle is set to **Active**.
4.  **Result:** The tool will automatically find the banner, scroll to it, and display a score out of 100.
5.  Click **Download Audit Report** to generate a forensic PDF (HTML) containing screenshots and legal citations.

### C. Performing a Batch/Bulk Audit (Researcher Mode)
1.  Open the popup and click **Open Dashboard ↗**.
2.  In the **Bulk Audit Entry** box, paste a list of URLs (one per line).
3.  Select a **Timeout** (e.g., 30s) based on site speed.
4.  Click **Start Batch Audit**.
5.  **Result:** The extension will autonomously:
    *   Wipe cookies/cache for the domain (Forensic Fresh Session).
    *   Open the site and search for banners (including inside iframes).
    *   Capture visual evidence and calculate the CAI score.
    *   Aggregrate all data into the dashboard table and the live chart.
6.  Click **Export Research CSV** to download the full dataset for your paper.

## 📊 Understanding the Results

### 1. The Scoring Engine (Base 100)
*   **100 - 70 (Compliant):** Symmetric design, easy rejection, clear language.
*   **69 - 40 (Partial):** Minor visual bias or multi-click rejection path.
*   **< 40 (Non-Compliant):** Critical dark patterns detected (e.g., No Reject button, Pre-ticked boxes).

### 2. Consent Asymmetry Index (CAI)
The CAI represents the "Friction Penalty." 
*   **CAI = 0.00:** Perfect parity (Acceptance effort = Rejection effort).
*   **CAI = 2.25:** Rejection requires 225% more effort (clicks) than acceptance.

### 3. Forensic Evidence Report
Every audit generates a professional report including:
*   **Interface Inventory:** A table showing which buttons (Accept/Reject/Manage) were detected.
*   **Vulnerability List:** Specific Dark Pattern codes (e.g., `DP-VM`) mapped to **GDPR Articles** and **DPDP Sections**.
*   **Evidence Screenshot:** A high-resolution capture of the banner as it appeared during the audit.
